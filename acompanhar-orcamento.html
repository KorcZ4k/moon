ORÇAMENTOS

Cada solicitação
tem um caminho.

Entenda as etapas previstas entre o envio de uma ideia e o possível início de um projeto.

FLUXO

01 / RECEBIDO

Solicitação enviada

As informações iniciais sobre a necessidade do cliente foram recebidas.

02 / ANÁLISE

Em avaliação

O projeto é analisado para compreender escopo, viabilidade e necessidades.

03 / PROPOSTA

Orçamento preparado

Uma proposta pode ser elaborada conforme as informações e condições do projeto.

04 / DECISÃO

Aprovação

Após a aprovação das condições, o projeto pode seguir para planejamento e desenvolvimento.

05 / EXECUÇÃO

Em desenvolvimento

O trabalho entra em execução conforme o escopo definido.

06 / ENTREGA

Concluído

As etapas previstas são finalizadas e a entrega é realizada conforme o projeto.

COMEÇAR
