PROJETOS

Cada projeto
tem uma trajetória.

Esta estrutura será utilizada para apresentar projetos em desenvolvimento e, futuramente, permitir o acompanhamento de etapas autorizadas aos respectivos clientes.

ESTRUTURA DE ACOMPANHAMENTO

01

Descoberta

Objetivos, necessidades e limites do projeto são identificados antes da definição da solução.

02

Planejamento

Escopo, arquitetura e etapas de desenvolvimento são organizados conforme a proposta aprovada.

03

Desenvolvimento

As partes previstas do sistema são implementadas e avaliadas progressivamente.

04

Revisão

O resultado é verificado e ajustado conforme os requisitos definidos para a entrega.

05

Entrega

O projeto é preparado para conclusão, publicação ou transferência conforme sua natureza.

ÁREA DO CLIENTE

Informação sem confusão.

Quando os sistemas de conta e projetos estiverem concluídos, clientes poderão visualizar informações autorizadas sobre seus próprios projetos em um ambiente centralizado.
